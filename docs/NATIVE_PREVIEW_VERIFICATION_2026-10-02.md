# 原生预览实机验证 · 2026-10-02

首阶段可运行预览，版本 `1.0.0-preview.1`。C# / .NET 10 / WPF 独立工程，未替换已安装旧版。参考 [Luma Bar 对照记录](LUMA_BAR_REFERENCE.md)与用户选定的 GPT 原型，所有界面由原生控件和矢量绘制构成。

## 环境与方法

Windows 11，i5-13500H，16 个逻辑处理器，16 GB 内存，2560×1600、150% 缩放；存在 Iris Xe 和虚拟显示适配器。发布目标 `win-x64`、自带运行时、ReadyToRun。当前预览默认软件绘制。

正常模式由独立 PowerShell 进程采样，启动或关闭工作台后等待 10 秒，再采集三个 5 秒区间。CPU 整机百分比为进程 CPU 时间 / 墙钟时间 / 16；不是单核心百分比。私有内存与工作集分别记录，不能用托管堆代替整个进程。

## 发现与修复

- 直接动画原生窗口宽高导致 WPF / HWND 尺寸回写，悬停和展开实际高度停在 76。新增尺寸回归检查先失败；改为直接确定窗口尺寸、只动画内部内容后通过。展开截图已逐张复核。
- 删除工作台大面积软件阴影，避免额外的渲染面和初始化成本。窗口使用系统圆角；岛以静态矢量分层绘制材质。
- 修正图标测量超出小按钮可用空间造成的截断；真实窗口截图复核。
- 截图和高频开关后立即采样曾测得约 88% 单核心 CPU。延长恢复时间，并以正常发布进程独立复核后得到上表；启动、压力操作及实际模型生成时占用可能更高。

## 验证范围

计时、任务、笔记、文件引用与窗口生命周期已用实际控件验证；AI 用协议测试验证流式解析、历史输入和取消，Key 用实际 Windows DPAPI 验证。尚未完成连接真实模型的对话验收、真实播放器全套控制、选定城市后的天气联网验收，以及游戏全屏、多显示器和其他缩放比例测试。

定时提醒、跨应用通知、旧版数据迁移和自动更新尚未接入。本轮提供首阶段可运行预览；完整客户端、正式安装包和官网在首阶段实机反馈后继续。

## preview.2 · 原生圆角修复

用户的实机截图暴露了首轮验收漏掉的系统外框：顶部有 10 像素白边，自绘外壳又与系统轮廓叠加。补充非客户区、真实鼠标和桌面合成截图检查后完成以下修复：

- 工作台将内容延伸到系统边缘，由 Windows 11 负责圆角、单层边框与阴影；移除自绘外壳及重复的缩放命中代码。
- 小岛移除逐像素透明窗口与外侧留白，使用 Win32 窗口区域裁切。三种窗口高度为 44、72、280 DIP，外围不保留矩形系统框。
- 导航、主按钮、普通输入与 API Key 密码框分别统一圆角与交互状态；密码仍由原生密码控件处理，导航悬停保持深色，银白主按钮悬停保持可读。
- 待办草稿弹窗使用系统标题栏、圆角和深色边框。实测发现固定高度会截断底部按钮，改为按内容确定高度后通过回归检查。
- 原生 AI 提示词的中英文描述同步以上窗口形态，现有功能范围保持准确。

验证器曾把只支持设置的 DWM 边框颜色属性当作可读属性，得到 `E_INVALIDARG`；改用实际窗口样式、区域及合成截图验证。后台启动的验收进程也曾未获前台权限，鼠标落到浏览器；验证时短暂接入前台输入队列后，两类按钮实测通过。此处理仅属于验收工具，正常客户端不接入其他应用的输入队列。

最终自带运行时发布包通过 13 项业务测试和 29 项窗口/交互检查，共 42 项；Release 构建与发布无警告、错误。中英文各 151 键，集合一致。已复核当前 150% 缩放下的工作台、原生草稿弹窗、小岛边缘以及最大化和还原画面；最大化跟随系统采用矩形边缘。

正常工作台独立进程等待 10 秒后，连续三个 5 秒采样区间：私有内存均为 72.74 MiB，工作集 137.92–138.16 MiB，CPU 时间增量均为 0。这里只代表短时空闲样本。完整截图和窗口压力测试后私有内存 81.38 MiB，20 个关闭窗口的弱引用全部释放；三个恢复期 CPU 样本为单核心 19.003%、0.623%、0.936%，即整机约 1.188%、0.039%、0.059%，首个区间仍有恢复开销。不能据此宣称长期无泄漏或运行中持续零占用。

原始证据：`dist/native-preview/native-round-red/report.json`、`dialog-native-red/report.json`、`acceptance-native-corners-final/report.json`、`idle-native-corners-preview2.json`。合成截图使用屏幕像素采集，能显示真正的系统轮廓与阴影，包括 `acceptance-native-corners-final/composed-workspace-ai.png`、`desktop-task-dialog.png` 和 `local-corners-normal.png`；WPF 渲染截图或 `PrintWindow` 本身不用于证明系统圆角。

本地桌面快捷方式已指向当前 `1.0.0-preview.2`。此更新仍为独立预览；其他缩放比例、多显示器和真实模型/播放器/天气验收范围见前文。
