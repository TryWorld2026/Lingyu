# 灵屿原生预览版 1.0.0-preview.4

独立 C# / .NET 10 / WPF Windows 客户端。此版本为预览版，旧客户端 v0.4.1 继续保留。

- 贴顶、悬停与展开形态，独立工作台和中英文窄窗布局。
- 专注支持暂停、继续、重启恢复；退出期间到期，在下次启动补记。完成卡片可关闭或开始下一轮，不抢输入焦点，关闭后不重复出现。
- 系统媒体控制、播放器选择与本地 LRC 歌词；默认音频输出变化后重连，设备或播放器缺失时明确显示状态。
- 天气城市选择、缓存刷新、更新时间与失败恢复。
- 待办、自动保存的纯文本笔记、文件位置暂存；Ollama 或自带 API Key 的多轮流式对话、本地历史、停止与重试。

下载 ZIP 后完整解压，双击 `Open-workspace.cmd`。运行时已包含，无需另装 .NET。`Open-visual-sample.cmd` 提供有标记的视觉样例。

数据位于 `%LOCALAPPDATA%/Lingyu/NativePreview`，不迁移旧版数据。通用定时提醒、跨应用通知、正式安装器和自动更新尚未提供。退出后没有后台进程发通知。物理睡眠/唤醒、全部 DPI 与硬件组合仍待实机验证。

核心 31 项、专注 23 项、完整原生 52 项和布局 68 项检查通过；发布目录中的 EXE 另通过 23 项专注检查。186 个双语键与资源/提示词契约检查通过。详情见 [专注验收记录](../NATIVE_FOCUS_VERIFICATION_2026-10-05.md)。

随附 `Lingyu-1.0.0-preview.4-win-x64.zip.sha256`，可核验 ZIP 完整性。程序尚未进行发布者代码签名。

## English

An independent native Windows preview built with C# / .NET 10 / WPF. It includes a dynamic island and workspace, persistent focus sessions with dismissible completion reminders, Windows media controls, local LRC lyrics, weather, tasks, plain-text notes, file references and streaming AI chat using Ollama or your own API key.

Extract the complete ZIP and open `Open-workspace.cmd`; the .NET runtime is included. Preview data is separate from the older v0.4.1 client. General scheduled reminders, other-app notifications, migration, an installer and automatic updates are not available. Hardware sleep/wake and full DPI compatibility still require validation. The app is unsigned; use the matching SHA-256 file to verify the archive.
