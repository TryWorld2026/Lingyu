# 灵屿 Lingyu v0.4.0

## 免费 AI 与品牌

- 新增 Lingyu AI 文字对话，支持 Ollama 本地模型与用户自带 API Key 的 OpenAI 兼容服务。
- 支持多轮对话、流式回复、Markdown、取消生成；Key 由主进程在本机加密保存。
- 软件功能免费，无需灵屿或上游账号、会员。云端模型服务可能按用量收费，费用由用户自选服务收取。
- 提示词、关于页、反馈入口、软件包信息与中英文官网统一为 Lingyu 品牌，并保留上游署名。

## 稳定性与安全修复

- 收紧 IPC 发送者与页面导航边界，移除 preload 的通用调用及环境变量暴露。
- 修复剪贴板历史关闭、清空后旧数据恢复、文件剪贴板 Unicode 格式和打开文件假成功。
- 修复多窗口待办、备忘录、闹钟及倒数日的并发保存覆盖；保存冲突提供双语反馈。
- 修复倒计时漂移、跨秒闹钟漏报与周期闹钟去重。
- 为网络响应和文件搜索设置边界；修复 PR 工作流权限及分支名注入问题。
- 官方下载不再自动跳转第三方代理。应用保留用户明确选择的代理设置。
- 升级 Electron 至 43.7.7，修复原生插件入口和 ABI 数据；三个辅助程序随包附带 .NET 10 运行时。

## 验证与范围

- 112 个测试文件、1,351 项测试通过，类型、构建、中英文翻译与注释检查通过。
- Electron 页面检查覆盖 15 个功能页、9 个设置分区和 35 个设置子页；原生包内 14 个模块与三个辅助程序资源通过验证。
- 当前 AI 提供文字对话。自动桌面工具、MCP、联网检索、上下文容量配置与天气预警尚未恢复。
- 真实模型、部分硬件操作及安装、卸载、升级数据保留仍需进一步验收。详见 [功能验收报告](https://github.com/TryWorld2026/Lingyu/blob/main/docs/FUNCTIONAL_VERIFICATION_2026-10-01.md)。
- 安装包尚未进行发布者代码签名；可信更新 manifest 认证及依赖审计发现仍待处理。

## English

Lingyu AI now supports local Ollama models or OpenAI-compatible services with your own API key, including multi-turn text chat, streaming, Markdown and cancellation. Software features are free, with no Lingyu membership or upstream account required. Cloud usage is billed by your chosen model provider.

This release fixes IPC trust boundaries, clipboard history, Unicode file clipboard formats, concurrent list saves, countdown and alarm timing, network limits, file search validation and PR workflow security. It updates Electron to 43.7.7 and bundles the .NET runtime required by the volume, brightness and temperature helpers.

All 1,351 tests across 112 files passed, along with type, build, translation and comment checks. AI desktop automation, MCP, web search, context-size configuration and weather alerts are not available yet. Real model and hardware compatibility, installation and upgrade data retention need further validation. The installer is unsigned; update authenticity and dependency audit findings remain open.
