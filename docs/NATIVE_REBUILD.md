# 灵屿原生重建

技术方向已确定为 C# / .NET 10 / WPF。此分支的 `native/` 是独立工程，不加载 Electron 或旧插件。

第一阶段交付可运行的常驻岛、展开面板和工作台。视觉基准为用户选定的八张 GPT 原型；真实音乐、时钟、音量直接使用系统数据。界面样例必须标注，不能冒充实际状态。

验证顺序：

1. 业务测试验证截止时间、暂停恢复、形态切换。
2. Release 构建后验证真实控件、系统音乐、音量、任务保存与工作台关闭释放。
3. 中英文、显示缩放和布局检查，保存真实窗口截图。
4. 采集整个客户端进程的内存和 CPU；常驻私有内存目标 120 MiB，工作台 240 MiB。目标须以实测为准。

第一阶段使用独立预览数据目录，不覆盖已安装版本或旧用户数据。实机反馈确认后再完成完整功能、迁移、v1.0.0、安装包与官网同步。
