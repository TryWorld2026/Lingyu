# Lingyu v0.4.1 产品重构与官网验收

本轮以用户选定的八张 GPT 分区视觉稿和两张品牌背景为共同视觉基准。产品先完成真实交互与界面重构，官网使用真实 Electron 组件的清晰截图，背景负责空间氛围，文字、导航与按钮使用 HTML。

## 产品

- 石墨黑、银白和低饱和紫；用户指定的白色胶囊标志，Windows 图标提供多个尺寸。
- 胶囊支持贴顶与悬浮形态。默认展开为音乐、实际天气及两日预报、时间和系统音量三栏；保留可配置总览。
- 设置与完整工具进入独立工作台。默认打开 AI，侧栏提供 15 个实际页面；窗口默认 1120×740，最小 880×600。
- 专注页组合实际番茄钟、可编辑待办与文件暂存。计时以截止时间计算，延迟回调只触发一次完成提醒；支持暂停、重置和跳过。
- 关闭工作台收回到后台，保留本次运行的会话与专注计时；退出时清除会话。最近最多 20 个会话可切换或删除，不保存到磁盘。
- 桌面提醒通过受信任 IPC 通知胶囊。标题、正文长度和本地 SVG 路径均校验；复杂工具不再撑开悬浮窗口。
- 设置快捷键直接打开工作台，旧的集成窗口配置不再阻止打开设置。行为设置明确说明当前窗口行为。
- 退出 API 补齐受信任主进程处理器，通过应用生命周期关闭窗口并清理后台服务；拒绝非信任页面请求。
- 软件功能免费；Ollama 与自带 Key 的 OpenAI 兼容服务直接连接用户选择的模型。云端调用费用由模型服务收取。提示词随功能同步维护。

## 验证

- TypeScript node / web 两工程、双语键检查和注释检查通过。
- Vitest：113 个测试文件，1,359 项测试通过。
- 真实 Electron + 真实 preload + 真实主进程存储：15 页 × 2 语言 × 2 主题 × 2 窗口大小，共 120 个布局组合通过，未出现横向溢出或渲染异常。
- 回归验证列表编辑、并发保存、剪贴板启停与失败反馈、计时、闹钟、设置子页、独立工作台启动失败和重试。
- 实际 HTTP 测试服务验证 Ollama / OpenAI 兼容协议、多轮流式回复、取消生成、密钥加密与服务地址变更后的凭据清除。
- 实际构建后的主胶囊与工作台 HTML / preload 均完成渲染验证。测试环境无定位时的天气不可用日志单独记录。
- 安装包中的 14 个原生依赖及 3 个自包含 .NET helper 验证通过；ASAR 内容与构建输出一致；Windows PE 版本为 0.4.1。
- 在独立临时配置中加载最终 ASAR 的实际主进程、真实 preload 与页面，逐一核对 15 个页面标题和内容。工作台关闭触发隐藏，再次打开复用原窗口；退出 API 正常关闭两个窗口，无 JavaScript 运行错误。
- 原生截图由实际组件渲染并使用演示数据。官网面板截图直接截取工作台中的计时、待办与暂存组件，未以生成图替代真实 UI。

## 官网

- 八区结构分别对齐首屏、形态演示、音乐与通知、专注与整理、AI、个性化画廊、更新与 FAQ、下载收尾。
- 使用选定的品牌背景，本地字体与许可、真实产品截图。图片采用 WebP；视频打开弹窗时才加载。
- 中英文、浏览器语言跟随及用户选择记忆、移动导航、键盘演示切换、视频弹窗、截图放大、FAQ 与下载失败回退均验证。
- 320、390、768、1366、1920 像素宽度与两种语言验证通过。1366×768 首屏包含标题、下载按钮与完整产品主体。
- 首屏资源约 0.49–0.66 MB，低于 1.5 MB 目标。正文对比度 17.95:1，辅助文字 9.19:1，下载按钮 17.33:1；图库文字与面板背景为 7.24:1，均高于 AA 的 4.5:1。
- 官网两种语言各 161 个键，142 个静态引用均存在；动态演示状态和发行说明在浏览器中验证。
- 下载数据只采用已公开的稳定 Release 与实际存在的安装包；静态回退在发行公开并核验后更新。

## 实际边界

当前 AI 不提供自动桌面工具、MCP、联网检索或上下文容量配置。真实大模型输出及实体音频设备、显示器亮度、蓝牙、电源和通知权限仍取决于用户环境，不能由协议与组件测试覆盖。安装包尚未进行发布者代码签名；本轮未在用户现有安装上执行安装、卸载或升级覆盖测试。
