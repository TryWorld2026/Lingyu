# Lingyu 免费 AI 第一阶段

日期：2026-10-01。状态：当前工作区已实现，尚未提交或发布。软件功能免费；用户选择的云端模型服务可能收费。

## 已实现与使用方法

全展开导航新增 **Lingyu AI**，设置新增 **AI 模型连接**，设置搜索可定位服务类型、地址、模型与 Key。

1. 本地 Ollama：先启动 Ollama 并安装模型；默认地址是 `http://127.0.0.1:11434`。点击“保存并加载模型”，选择模型后“保存连接”。
2. 自带 Key：选择 OpenAI 兼容 API，填写 Base URL、模型和 Key。默认示例地址是 `https://api.openai.com/v1`；其他服务填写其提供的兼容 Chat Completions 基地址。远端兼容服务必须使用 HTTPS，本机 `localhost`／`127.0.0.1`／`[::1]` 可使用 HTTP 和空 Key。
3. Enter 发送，Shift + Enter 换行；支持多轮文字、中文流式回复和 Markdown。“停止生成”或离开 AI 页会取消当前请求。“新对话”清除当前窗口的会话。

本地模式不调用上游账号／提示词服务，不要求 Lingyu 账号或 Pro。模型列表使用所选服务；兼容服务可手动填写模型名。软件不验证会员或锁定模型，具体模型的可用性、容量和费用由该服务决定。

## 提示词与数据边界

- 唯一活动提示词 builder 是 [systemPrompt.ts](../src/main/ai/systemPrompt.ts)，由 [主进程 AI IPC](../src/main/ai/ipc.ts) 注入。AGENTS.md 同步该维护入口，后续能力变更必须同时更新提示词和测试。
- 当前是文字助手，没有自动桌面工具、MCP 或联网检索。提示词明确说明没有文件、剪贴板、应用状态、实时天气和 shell 的自动访问权限，不允许声称已执行动作。
- 消息和本地系统提示词直接发送到用户配置的地址。Key 不进入会话或系统提示词。远端兼容服务的 HTTP 与所有自动重定向被拒绝，避免将兼容服务的 Key 自动转发到其他地址。
- 用户在密码输入框填写新 Key；保存与解密由主进程执行。凭据用 Electron `safeStorage` 加密，独立保存在 `userData/lingyu_ai/connection.json`，不进入通用 renderer store。公开配置只返回 `hasApiKey`；不提供明文读取接口，也不回显服务错误正文。
- 同一服务地址保存其他选项可保留 Key；更换服务类型或地址后必须重新输入。点击移除后保存会删除 Key。加密不可用或解密失败时返回明确错误，不退回明文存储。
- 聊天记录只保留在当前窗口的运行内存中；切换页面可保留已有记录，关闭窗口不持久化。取消／失败的半截回复不会进入下一次发送的上下文。Markdown 不渲染图片，避免回复中的远端图片自动请求。

调用具有窗口和入口校验；同一窗口最多一个生成任务。模型列表超时 15 秒，对话超时 180 秒；请求最多 512 条消息、每条 256 Ki 字符、总 JSON 2 MiB。模型列表响应最多 1 MiB，对话响应最多 8 MiB，并限制未完成片段。以上是资源上限，不是模型 token 容量，当前没有 1M 上下文配置或自动裁剪。
