# Lingyu Built-in Search

After future version updates, the location of certain settings may change. This documentation may not be updated immediately, so you'll need to learn how to use Lingyu's search box to find specific settings.

## Search Box Location

The search box is located in the top-right corner of Lingyu's maximum expanded interface. You can directly type your search content in the box to quickly locate relevant settings.
